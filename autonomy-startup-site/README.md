# Autonomy startup website

A responsive React + Vite landing page with animated abstract system visuals, platform sections, a proposed four-week discovery plan and an enquiry form.

## Run in VS Code

1. Install Node.js (LTS) if it is not already installed.
2. Open this folder in VS Code.
3. Open Terminal → New Terminal (PowerShell).
4. Run:

   ```powershell
   npm install
   npm run dev
   ```

5. Open the local address Vite prints, usually `http://localhost:5173`.

## Notes

- Edit `src/App.jsx` for page content and `src/styles.css` for styling.
- The enquiry form is front-end only. It currently validates fields and shows a demo success state. Connect it to your own backend or form service before publishing.
- Replace the AUTONOMY wordmark, copy and contact details with your final startup identity.
- Build for production with `npm run build`.
